The problem

Resemblance is easy.
Transfer is hard.

Finding a landscape that looks like Mars takes a search box. Designing a terrestrial test whose result legitimately transfers to a Mars decision takes measurable requirements, a shared spatial support, and an honest account of every gap. TerraTrace is built for the second problem.

The method

One scale. Both worlds.
No single score.

Each area of interest is warped to its own local azimuthal-equidistant metric grid — Mars on a 3,396,190 m sphere, Earth on WGS84 — so slope and relief are measured in true, comparable metres. Candidates are ranked by Pareto dominance; a tie is a valid, honest result.

01 · INGEST

Real NASA + ESA data

MOLA MEGDR for Mars; Copernicus GLO-30 / USGS 3DEP for Earth.

02 · REPROJECT

Per-body metric grid

Correct ellipsoid, correct metres — not a shared degree hack.

03 · GATE

Refuses bad data

Water/sentinel masking; blocks units that are mostly flat zero.

04 · DECIDE

Pareto, not a score

Six descriptors; tie / indeterminate / blocked are first-class.

The six descriptors

What "terrain" actually means
at map scale.

slope distribution · local relief · detrended ruggedness · low-slope connectivity · aspect dispersion · hypsometric integral. Each is defined, unit-bearing, and traceable to a source through the evidence graph.
